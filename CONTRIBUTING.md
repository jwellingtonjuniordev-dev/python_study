# Contributing to Python Study

Obrigado pelo interesse em contribuir com este projeto!

Este repositório foi criado com o objetivo de documentar uma jornada de aprendizado em Python, reunindo conceitos fundamentais, exercícios práticos e pequenos projetos.

## Objetivo do Projeto

O objetivo é criar uma coleção organizada de exemplos e exercícios que possam servir como material de estudo para iniciantes e também como registro da evolução do aprendizado em Python.

---

# Como contribuir

Existem várias formas de contribuir:

* Corrigir erros de código;
* Melhorar a documentação;
* Adicionar comentários explicativos;
* Corrigir erros de digitação;
* Sugerir melhorias nos exercícios;
* Criar novos desafios;
* Adicionar novas aulas.

---

# Estrutura do Projeto

Cada aula aborda um tema específico da linguagem Python.

Exemplo:

```
aula1_variaveis_e_tipos.py
aula2_inputs_conversao_de_dados.py
aula3_estruturas_condicionais.py
...
```

Cada arquivo deve conter exemplos simples e exercícios práticos relacionados ao assunto estudado.

---

# Padrão das Aulas

Sempre que possível, uma nova aula deve seguir esta estrutura:

1. Explicação do conceito.
2. Exemplo simples.
3. Exercício guiado.
4. Desafio prático.
5. Projeto ou exercício extra.

---

# Organização do Código

Procure manter o código:

* Simples;
* Bem indentado;
* Comentado quando necessário;
* Com nomes de variáveis descritivos;
* Fácil de entender para iniciantes.

Exemplo:

```python
nome = input("Digite seu nome: ")
print(f"Olá, {nome}!")
```

Evite abreviações difíceis de compreender.

---

# Documentação

Ao adicionar uma nova aula:

* Atualize o README.md;
* Atualize o DOCUMENTATION.md;
* Atualize o ROADMAP.md.

Toda nova funcionalidade deve estar documentada.

---

# Nomeação dos Arquivos

Utilize o seguinte padrão:

```
aulaXX_nome_do_assunto.py
```

Exemplos:

```
aula17_arquivos.py

aula18_modulos.py

aula19_decorators.py
```

# Boas Práticas

Antes de enviar uma contribuição:

* Verifique se o código funciona corretamente;
* Mantenha a organização do projeto;
* Evite duplicação de código;
* Escreva exemplos claros;
* Preserve o foco didático do repositório.

---

# Fluxo de Contribuição

1. Faça um Fork do projeto.

2. Crie uma branch:

```
git checkout -b minha-contribuicao
```

3. Faça suas alterações.

4. Faça um commit:

```
git commit -m "Adiciona nova aula sobre arquivos"
```

5. Envie para seu repositório:

```
git push origin minha-contribuicao
```

6. Abra um Pull Request.
